## 1. 目标

面向访客的个人档案站：**项目展示 + 个人叙事为主**，求职为软性附带（联系与简历入口可见，但不做成硬着陆求职页）。

成功标准：

语言：

- 中英双语，**默认中文**

## 5. 视觉设计

### 5.1 主题隐喻

- **重度 16-bit**，气质偏 SNES/世嘉 RPG
- 整站隐喻：**RPG 状态 / 菜单界面**
- 主色：明亮冒险感 — **天空蓝 + 草地绿 + 暖黄强调**
- 菜单窗内部：**米黄/浅色窗芯 + 深色字**
- 边框：**经典双线/三线像素浮雕框**；首屏标题窗可略厚
- 导航：**顶部横条**像素菜单（含移动端折叠菜单）
- 外景：简单像素天空 + 草地；**首发纯 CSS 分层横条**，结构预留可换 tile/手绘
- 滤镜：**无** CRT/扫描线
- 光标：系统默认
- 声音：首发无；预留扩展点（注释或空模块即可）

### 5.2 字体

- 短标题 / 按钮 / 标签：像素字体
- 正文（简介、Journey、项目描述）：可读非像素字体（中英）
- 像素字仅用于短文本，避免中文长段落像素化

### 5.3 关键组件表现

- Hero：像素角色占位 + **对话框招呼**；下方 Short Profile 用普通双线内容窗
- Projects：**二或三列像素卡片栅格**（图鉴/道具栏感）
- 语言切换：当前语种按钮 + 下拉菜单
- 动效：**中等** — 角色待机、区块切入、语言切换过渡 + 基础出现/hover（约数处有意识动效，避免过载）

## 6. 技术方案

### 6.1 栈

- **Next.js（App Router）+ TypeScript + Tailwind CSS**
- 新建于 `D:\Portfolio`
- 动画：CSS 为主，必要时少量客户端动效库（可选用 Framer Motion，非必须）
- 包管理：npm（单一包管理器）

### 6.2 路由与 i18n

推荐两种等价实现之一（实现计划阶段锁定）：

1. **`app/[locale]/...`** + 字典文件（`messages/zh.json` / `en.json`）  
2. 或单路由 + React Context 切换文案（静态导出更简单）

约束：必须支持静态导出；默认 `zh`。

### 6.3 静态导出与部署

- `next.config` 使用静态导出（`output: 'export'`）
- 图片等资源放 `public/`
- 部署目标：**香港区域**静态托管（暂不 ICP 备案）
- 不依赖 Node SSR 运行时

### 6.4 数据组织

建议内容与展示分离，例如：

- `src/content/` 或 `src/data/`：projects、education placeholders、journey placeholders、skills、profile copy、contacts
- 组件只消费数据，便于用户后补

## 8. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 中文像素字难读 | 像素字仅短标题；正文可读字体 |
| 重度像素显得玩具、不专业 | RPG 菜单框 + 米黄对话框 + 克制动效，避免噪点滤镜 |
| 静态导出与 i18n 路由冲突 | 优先 Context 或预渲染双语言路径；避免服务端独有 API |
| 简历 PDF 缺失 | 约定路径 + 文档说明；UI 不假装文件已存在若采用检测策略 |
| 大陆访问海外 CDN | 部署定在香港区域静态托管 |

## 9. 实现顺序（概要）

1. 脚手架 Next + Tailwind + 静态导出配置  
2. 设计 token（色板、像素框组件、字体）

4. 各板块按 IA 落地 + 占位内容  
5. 动效与角色占位  
6. 本地 build 验证静态导出  
7. 部署说明（香港托管）写入 README
