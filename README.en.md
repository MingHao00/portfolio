## Focus

The personal portfolio of **Junhao Huang (Jimmy)**. The career page shows the work. The personal page shows the day-to-day. The live site is what a visitor opens; this repository is the source.

The site is built around one line:

> A Vibe Coding practitioner working on AI applications.

Three pieces of work:

1. **Portfolio site**: This repository. HTML, CSS, and vanilla JavaScript, in Chinese and English. [Open the site](https://jimmy-portfolio-7j0.pages.dev/)
2. **N-BEATS visitor forecasting**: Co-first author. N-BEATS compared with common time-series models on daily visitors to Jiuzhaigou and Mount Siguniang. [Paper](https://doi.org/10.3390/su16188227)
3. **ElderBrain rules Q&A**: A Python full-stack RAG that answers D&D rules only from the Chinese SRD 5.1, and cites a source for each claim. [Source](https://github.com/MingHao00/ElderBrain)

## Pages

Two public static pages, plus a design spec that stays in the repository. The URL is the filename. There is no build step.

* **Career (`index.html`)**: Navigation, language switch, portrait with orbiting dots, education, about, three selected works, a journey, and contact. The email button copies the address.
* **Personal (`personal.html`)**: Hobbies (basketball, fiction and anime, Street Fighter, tournaments to visit), a draggable globe, a daily routine, future plans, one song, a move trainer, and a thank-you close.
* **Design spec (`design-system.html`)**: Color, type, radius, shadow, and motion tokens. It is not in the nav. It is there for anyone changing the styles.

The three project cards on the career page link to this repository, the paper DOI, and ElderBrain.

## Open locally

No install step and no build command.

```bash
git clone https://github.com/MingHao00/portfolio.git
cd portfolio
```

Open `index.html` or `personal.html` in a browser.
