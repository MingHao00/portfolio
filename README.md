# Portfolio

个人作品集站点（Next.js 静态导出）。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物在 `out/` 目录。将 `out/` 上传至香港静态托管即可部署。

## 简历

将 PDF 简历放到 `public/resume.pdf`，站点可通过该路径提供下载。

## 项目链接说明

`https://github.com/MingHao00`。若已有独立仓库，请更新
`src/content/projects.ts` 中对应 `link`。
